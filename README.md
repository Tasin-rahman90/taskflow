# Taskflow React

A responsive task dashboard built with React and Vite. Add tasks, filter and search them, mark work complete, and remove tasks. Your task list is saved in the browser with localStorage.

## Run locally

1. Install Node.js (18 or newer).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

## Production build

Run `npm run build`; the optimized site is written to `dist/`. Use `npm run preview` to serve that build locally.
